# assets3d_anime

Lightweight anime-style fallback assets for headless Blender renders.

- `characters/anime_hero.obj`: UV unwrapped low poly character proxy mesh.
- `characters/anime_hero_rig.json`: basic rig bone hierarchy metadata used by pipeline fallback.
- `props/stylized_ground.obj` and `props/stylized_gate.obj`: UV ready environment props.
- `textures/*`: flat anime base tones and simple normal/spec placeholders.
